Alicization is a monorepo for a digital-life style assistant across desktop (Electron/Vue), web (Vue), and mobile (Vue/Capacitor), with the main current runtime surface in apps/stage-tamagotchi. Core shared business logic lives in packages/stage-ui and packages/stage-shared. The repo uses pnpm workspaces, TypeScript, Vue 3 Composition API, Pinia, VueUse, UnoCSS, Eventa for IPC/RPC, injeca for DI, and Vitest/ESLint for testing and linting.
