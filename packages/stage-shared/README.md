# Stage Shared

Stable contracts and rendering semantics shared by the desktop and other surfaces. The desktop runtime owns Phase 1 personhood, memory, emotional appraisal and initiative.

## Dialogue expression

`alicization-dialogue-embodiment.ts` projects committed dialogue emotion and performance into renderer and speech envelopes. Valid emotion, delivery and emphasis retain their authority across repeated turns. Sparse emotional input carries the previous valid emotion, then falls back to neutral. Generated reply wording and diversity counters do not define a new emotional state.

Explicit facial and action cues are preserved when the actual renderer manifest supports them, including their first occurrence. Sparse cues retain the existing bounded cue fallback. This does not provide semantic motion planning or a new cognition runtime.

The continuity regression covers quoted emotional words, repeated care across thirty turns, missing emotional evidence, first authored gestures, and downstream dispatcher/voice consistency.

## Interaction intent

The desktop transport finish contract separates raw provider text from the accepted reply projection and declares whether the main process already committed the conversation. Other surfaces consume these facts; they do not introduce a second settlement or memory authority. Provider-specific schema experiments stay in the desktop runtime.

`AlicizationInteractionIntent` is a bounded projection of the existing desktop conscious frame and answer plan. It carries card/turn identity, purpose, focus, evidence references and a maximum two-minute lifetime through an embodiment script. It does not create personhood or represent a completed action. Script normalization discards an intent belonging to another turn. `interaction-transition.ts` adapts TalkingHead's MIT easing for preparation, sustained gesture and release; the complete license ships in desktop resources.
