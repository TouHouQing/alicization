# 原生编辑器方法与长对话上下文闭环

本轮继续 Phase 1 的同一人格、同一责任和同一执行证据链。新增方法复用继续使用已有 LifeTurn、WorkPlan、Effect、风险许可、独立验收和技能注册表；没有另建自动操作器或第二份目标状态。

## 原生方法边界

可学习的形状是四步有序事务：读取当前窗口控件、选择唯一输入框并填写、重新读取控件、选择当前观察中唯一匹配的保存按钮。每次调用明确提供当前窗口标题、保存标签、文字和目标文件。保存后以实际 UTF-8 文件字节独立验收。

模板移除私人示例、原窗口名、文件名和保存标签。文件哈希从本次明确输入的文字计算，模型不能提供另一份无关哈希来替代内容验收。当前请求中明确声明的文字可以修正模型缩写；方法版本、窗口、按钮或文件不匹配时拒绝修正，不猜测另一个目标。JSON 字符串中的指令保持为数据。

评估使用后台自有 WinForms 编辑器、真实 Windows 控件适配器和真实文件保存，覆盖两组多语言及换行输入、参数错误、接口变更、取消、控件缺失、控件歧义、保存拒绝、实际字节变化、窗口关闭。评估器通过原生 Job 管理子进程，并核对 nonce、PID/启动时间、HWND、所有显示器之外的位置及未获焦点状态。发生未知效果后停止进一步复跑。

这只证明标准编辑器事务。任意桌面程序、WPF 菜单、前台快捷键、真实物理接管和真实混合 DPI 仍须各自的实际证据，不能从这里推断。

## 长对话失败修复

原 v323 实际成品文字测试在第九个请求遇到本地上下文预算拒绝，尚未发送 HTTP 请求。此前文字流和嘴形检查通过，失败不能归因于网络或伪装成模型成功。

新请求投影对历史对白与时间线中的重复原文建立精确字典，也可共享说话者限定语内部的相同原文。保留每段记录的说话者、来源、时间、当前状态、顶层修正和检索证据；不修改数据库。字典只有减少实际字节数时才采用，且可以逐字段精确还原。身份、当前请求、工具接口和输出最低预算继续受保护。无法容纳的请求仍明确失败，不截断 JSON 或虚报生成结果。

实际失败记录的只读重放额外节省 716 字节；原始记录逐字段还原通过。它是针对原故障的离线证据，不能替代新成品的真实提供商文字测试。
