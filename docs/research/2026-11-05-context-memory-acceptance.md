# 上下文压缩与对话检索验收

日期：2026-11-05。结果：本轮实现和以下功能验证通过。

## 交付

- 近期记忆按预算保留问答组，替换固定 6 条发言窗口。保留边界完整；过长历史文本仍可摘录，完整原文由对话存档持有，当前新输入单独保留。
- 重要句摘录、关系/情绪/约定保留排序、有限时间线合并，以及有预算说明的推理投影。
- 回复提交后的语义选择；模型只选择既有摘录 ID。本地保留角色、发生时间、措辞与来源，结果必须缩小体积。
- 内存检查、完整源检查点 CAS、来源撤回预检及写入事务复检；后台任务可被新对话抢占，失败保留已提交的提取式检查点。
- 原始对话 FTS5 索引、一次性旧记录回填、相关性/时间游标、精确来源页回读，以及后续页的引用证据校验。
- 长期记忆相关性排序后的互补证据选择，减少近义重复材料挤占上下文。

设计、上游实现与数据边界见 [研究说明](2026-11-05-context-memory-optimization.md)。五个项目的 32 份源码及许可证共 1,032,436 字节，提交和文件摘要见 [来源清单](2026-11-05-context-memory-sources.json)。
