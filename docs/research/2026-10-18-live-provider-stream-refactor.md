# 实时正文、显示游标与最终提交的重构

目标是让桌面在模型仍生成时显示正文并启动对应口型，保留人格、记忆、工具执行与表达的一致性。此前的实现分别在主进程和界面等待完整结果，两道等待均已拆开。

## 数据与职责

- 主进程 Provider reader 逐块消费真实 SSE。增量 JSON decoder 只提取根级 `reply`，可先读取一个白名单 `emotion` 头部准备表情；思考、工具参数、记忆元数据和嵌套对象不进入正文。
- 输出契约先放情绪和正文，随后才生成其他状态。完整状态仍接受原有结构、记忆证据和语义审查。执行完成、存储记忆、具体承诺和转述历史等断言由既有 grounding 分类器暂停后续发布，待证据审查后再放行。
- 正文 append 包有单调序号和 UTF-16 offset。complete 包只确认序号与长度，不再携带或重播正文。最终 finish 保留完整权威结果与持久化事实。
- UI 的增量 presenter 持续消费到达的正文，不阻塞网络接收。保留自然语速、标点停顿、拼音上下文和口型过渡；第一字可以在 Provider 结束前显示。`text-presented` 让聊天、角色气泡、字幕与 Live2D 共享可见位置。
- 实际语音消费已放行正文；选择语音服务时由音频控制嘴部，纯文字模式由文字游标控制嘴部。逐字显示不会重新触发全身动作。

收到正文、用户已看到正文、最终通过审查，是三个不同事实。早期正文包不允许进入长期记忆、人格学习或训练。网络断流、用户中断、最终审查失败，都保留用户已看到的前缀并标明未完成；不伪造成功、不静默替换、不从头重播。已发布正文之后禁止网络重试及新工具动作覆盖这一轮。

中断的局部消息保存显示快照和禁用学习的标记。历史回放或重新加载不能露出用户尚未看到的尾部；会话 generation 已失效时不写回旧前缀。最终成功仍由原有主进程 EventLoop 提交人格、记忆与工具事实，未用可见 UI 状态代替这些事实。

## 边界

正常 JSON 主流程支持实时提取。协商为纯文本且当前步骤不能调用工具时，也支持增量正文。未知围栏、数组形状和显式格式修复保留有界的完整解析路径；工具步骤中的不明确自然语言不会被当成最终回复提前说出。接收正文最多 12,000 UTF-16 单位，原始结构流另有大小和嵌套深度上限。

正文仍按约每秒四个中文字显示，以保留之前要求的自然口型速度；它不是把网络 token 的突发速度直接用作讲话速度。长回复允许产生显示积压，可以随时中断。此重构不声称所有语义风险都能通过字符级检查发现，也不把部分输出当作已审查的长期事实。

## 验证方式

本地真实 HTTP SSE 因果测试让服务端在收到第一段正文前不发送后续内容；另有私有字段、Unicode、跨包转义、重复包、缺包、替换、断流和禁止重试等测试。渲染端测试在模拟 Provider 尚未完成时检查首字与口型钩子，并检查最终只提交一次、中断保存及禁用学习。

实际体验使用私有 Windows desktop 的 Live2D Hiyori 和真实配置的模型，不切换输入桌面。通过正常聊天 UI，比较首个可见 DOM、首个嘴部输入和 Provider finish 事件的系统时钟时间；另检查中断后重新加载仍保留前缀。生产日志仅增加请求哈希与时间戳，不记录额外正文或凭据。

## 已执行的验证

定向回归共 101 个文件、1,435 项测试全部通过，无跳过项。根目录 `pnpm typecheck`、`pnpm lint:fix`、桌面生产构建和 Windows 安装包构建均成功；lint 仍有 730 个 warning、没有 error，未将 warning 数描述为零。

编译输出的 Live2D 定向体验通过 62 项检查，覆盖实际首字显示、口型、消息去重、自然语速、中断和重新加载。两轮真实回复的首个嘴部输入／DOM 分别在首个正文发出后 3／6 毫秒与 2／5 毫秒出现，均早于 Provider finish。独立的语音回归通过 39 项检查，覆盖实际静音播放的 SAPI／PCM、音频口型主导权、打断、静默回落及旧音频不复活。两轮均在独立 Windows desktop 正常退出，输入桌面保持 Default。

首轮成品体验保留了一份失败记录：短回复的正文与 finish 只相差 2 毫秒，实际 DOM 需要 5 毫秒到达，因此不可能满足该轮“DOM 必须早于 finish”的断言。这一结果不说明系统等待了完整结果，也不能充当真实流式的成功证明。验收保留短文本的正文到显示延迟，并增加每次内容不同的长文本请求：要求生成窗口至少 150 毫秒，且嘴部输入和真实 DOM 都在生成结束前开始。HTTP SSE 因果测试另从协议层证明接收端不需要后续数据才能发布首段正文。

证据分别保存在 `output/live2d-incremental-stream-regressions-20261018.json`、`output/live2d-incremental-stream-compiled-20261018/report.json`、`output/live2d-incremental-stream-voice-compiled-20261018/report.json` 与初次成品记录 `output/live2d-incremental-stream-packaged-20261018/report.json`。这些是本次流式和表达改动的定向验证，不代表重新认证所有产品功能或 Phase 1 生命闭环。
