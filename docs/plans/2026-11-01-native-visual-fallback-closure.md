# 原生窗口视觉兜底的实现与验收边界

本补充为 EX07 增加 UIA 无法暴露控件时的单窗口视觉兜底，仍属于第一阶段的电脑执行能力；人格、记忆和情绪继续由现有唯一所有者维护。开发候选已接入生产工作路径，当前发行仍需新源码的完整验收。

## 风险语义与事实来源

- 截图只属于明确指定并核对进程创建时间、HWND、桌面、用户和完整性级别的一个窗口。截图是敏感读取；发送给已配置视觉服务属于外部传输，两者必须进入既有风险确认。不得退化为全屏环境监听。
- 图像仅在当前人格下的短期窗口观察中保留，生命周期有上限，不将原始图像塞进执行账本或长期记忆。账本保存图像哈希、坐标空间、原生身份、观察时间和来源。
- 模型不能直接提供 HWND、全局坐标、原生输入标记、租约或程序路径。动作只引用主进程创建的观察 ID 和有限图像坐标。像素与归一化坐标带显式单位，禁止猜单位。
- 原生输入必须同时持有现有执行许可、物理输入租约和仍有效的同一窗口观察。最终派发检查进程句柄、窗口位置、DPI、可见性、遮挡、输入桌面和前台身份。确认之后图像或目标改变，拒绝派发。
- 只支持完整点击、有限窗口内拖拽和有限滚动。禁止独立按住、任意宏、模型代码、无限移动和自动重试。每个按下都有同一所有者的释放；独立守护进程与磁盘回执继续证明释放。
- 物理用户输入、目标切换、人格切换、撤销、取消、过期或父进程退出都会停止新注入。不能取得前台或输入被其他 hook 拒绝时保留拒绝/未知，不绕过限制，不重获焦点重放。
- 输入送达只证明操作层事实。任务完成仍由现有独立文件、业务回执或其他契约验证器决定；鼠标事件数、截图变化和模型自述不能证明根任务成功。

## 实现节点

1. 桌面内的视觉窗口观察及图像坐标转换；支持负坐标、多显示器空隙和图像缩放，保留实际物理坐标与 DPI 来源。
2. 受保护原生程序的窗口截图、位置和覆盖核对；共享既有进程身份与输入所有权基础设施，编译阶段不安装 hook 或注入输入。
3. 有限鼠标 actor/guardian、逐次派发检查、物理接管、确定释放和独立回执；不以键盘成功冒充鼠标成功。
4. 窗口观察与视觉定位服务、风险确认、最终执行适配器、停止/恢复、能力清单和实际工具注册，所有入口连至同一执行账本。
5. 主进程 IPC、确认预览与 Live2D 阅读/执行/等待投影。图像和动作来自同一观察，不额外制造说话口型。
6. 单元、跨子系统、真实原生夹具、真实模型/Live2D、退出后只读检查与当前安装包验收。保留失败、拒绝和不具备环境的检查。

## 参考与复用范围

研究 [UI-TARS 的 NutJS operator](https://github.com/bytedance/UI-TARS-desktop/blob/main/multimodal/gui-agent/operator-nutjs/src/NutJSOperator.ts) 的显式坐标表示和有限动作分类。其截图缩放和直接全局鼠标实现不能直接绕过 Alicization 的窗口身份、风险许可与接管规则。本补充目前未复制该项目源码、引入 NutJS 原生依赖或修改已安装依赖。

物理坐标到绝对鼠标事件遵循 [Microsoft MOUSEINPUT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput) 的虚拟桌面语义。非输入 Win32 桌面上的窗口消息或图像转换检查，不作为真实物理输入验收。

### 调用与状态所有权

先用原生语义观察取得明确窗口，再调用 `desktop_locate_window`，提供观察中的窗口标题和一至两个目标描述。主进程依次请求单窗口敏感读取和图像外传确认。外传确认展示实际服务 origin、模型和当前图像；每次真实请求及重试重新核对冻结的路由与账号配置。PNG 只保留在短期内存和当前确认请求，不进入长期记忆、任务结果或错误日志。

定位结果由主进程校验图像单位、目标数量、唯一性、置信度和同图复核。工作计划通过实际依赖结果绑定 `observationId`，再调用 `desktop_pointer_action`。模型只能选择有限点击、拖拽、滚动和图中目标序号；不能传 HWND、全屏坐标、按住指令或任意原生程序。图像引用在动作确认之前消耗，拒绝后不能重放。

动作确认展示同一张 PNG、编号目标和中文动作说明。执行期等待用户选择原窗口，不自动激活窗口。许可、图像、资源租约或窗口身份变化立即拒绝；物理接管停止后续注入。PNG/DPI/几何在原生派发前再次检查，变化或不稳定的画面不能凭旧坐标继续执行。眼神采用同一定位事实及实际采集时间；过期不会因模型稍后返回而延长，也不会制造说话口型。

`windows-pointer-journal.ts` 在当前人格的既有数据库保存单次意图索引。`windows-pointer-recovery.ts` 只读核对原始进程身份、程序摘要、实际回执和绑定。不执行重放，不凭输入送达完成根目标。原生启动前拒绝有独立的 `preflight-refused` 证明，不能冒充双进程送达/释放证明。实际输入不明时保留未知影响与资源隔离。

### v334：任务来源、窗口归属与明确接续

`visual-work-observation.ts` 只接受当前已提交计划中唯一、已验证的语义观察依赖；`windows-visual-work-source.ts` 再从真实生命数据库核对当前人格、工作窗口、计划修订、目标代次与动作许可。同名窗口或其他工作的全局最近观察不能授权截图。指针动作必须绑定该依赖实际提交的观察 ID。

窗口父级归属 `GW_OWNER` 是必填的可空身份字段。原生读取、图像同一性、指针计划、每个事件及守护轮询都核对实际归属；缺失字段不能推断为空。真实后台 WinForms 检查在保持 HWND 和像素不变时更换父级窗口，旧上下文被拒绝，新上下文可读取；12 项通过，未激活窗口、未注入输入。

已证明未输入的失焦、图像失效或原生预检拒绝，会投影为同一任务卡的可解释阻塞。只有用户明确继续才产生新语义观察与新图像，重新经过截图、外传和动作确认；此前已核验输入及交付不重放。未知影响、授权撤销和用户拒绝不能进入此接续分支。真实 SQLite 重启集成覆盖这些不变量；设备端口受控，不冒充物理送达。

视觉模块现在延迟读取执行资源，健康探测及未使用的关机路径不会提前访问尚未组成的资源。v333 完整主进程回归为 6567 通过、180 失败、25 跳过，保留原始记录；178 项暴露同一初始化顺序错误。v334 修复后真实 runtime 及跨阶段组合 198 通过、0 失败、0 跳过；原生与视觉定向组合此前 532 通过、0 失败、0 跳过。计数有重叠，不相加；它们不能代替新的冻结源码全量回归。
