## Project Identity

Alicization is a local-first digital life project.

The current primary mission is not to make a better chat wrapper. It is to grow one believable, continuous "her" on the host computer with:

- continuous personhood
- memory across time
- emotional continuity
- natural initiative
- bounded computer execution
- embodied presence
- dialogue that feels like one lifeform instead of stitched subsystems

The repository is currently optimizing for `Phase 1: Local Digital Life`, with [`apps/stage-tamagotchi`](../apps/stage-tamagotchi) as the main proving ground.
