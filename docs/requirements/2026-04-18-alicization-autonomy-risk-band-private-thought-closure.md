# 2026-04-18 Alicization Autonomy Risk Band Private Thought Closure

## Goal

继续把 Alicization 从“更像一个持续存在的人”推进到“更像一个会自己拿主意的人”，重点补齐：

1. 低风险先做 / 风险带自治。
2. 持续私有思维流，而不是每轮都像重新开机。
3. 自传 episode、宿主节律、dream recovery 进入同一条主动 runtime 闭环。

## Problem Statement

上一轮已经补上：

1. durable self-generated goals
2. autobiographical continuity retrieval
3. proactive cadence
4. host rhythm
5. self-facing fast path continuity

但还存在几个使“自主性”发虚的缺口：

1. proactive mutate 仍然主要停在 “要不要我做”，还没有真正形成低风险先做、中风险先问、高风险永远问的风险带。
2. private thought 虽然存在，但不够像持续流动的 inner line，缺少跨 tick / 跨 opening 的 thought carry。
3. dream 还只是在调 fatigue，没有真正回收主动节律。
4. autobiographical episodes 已经出现雏形，但还要接回 recall prompt surface，成为能被再次讲述的 lived history。

## Architectural Direction

坚持一条原则：继续在现有 Alicization digital-life runtime 上做闭环，不建立第二套心智系统。

本轮聚焦：

1. 在 `claw-fabric + autonomy-actuation` 上定义 proactive risk band。
2. 在 `private-thought-loop` 上引入 previous-thought carry，使 inner line 可以持续 simmer。
3. 在 `runtime-dream + proactive-feedback` 上增加 dream recovery 对主动节律的回收。
4. 在 `runtime-organic-memory-prompt` 上把 autobiographical episodes 作为自传回忆而不是普通 fragment。
5. 在 `intention-stream` 上把 autobiographical goal / motive agenda / resurfacing desire 聚成 simmering project。

## Deliverable

1. Low-risk proactive code edits can self-start on rollbackable code-agent bodies.
2. Medium-risk proactive mutations require affirmation.
3. Private thought continuity can carry across the same inner carrier instead of resetting every tick.
4. Dream metabolism can cool proactive momentum without erasing initiative trust.
5. Autobiographical episode recall enters organic memory prompt surface as lived self history.

## Constraints

1. 不破坏现有 confirmation / callback / result-learning 闭环。
2. 不把 generic desktop/software automation 错误降级成 low-risk self-start。
3. 不修改 `N.E.K.O/` 业务代码。
4. 所有行为变化都必须继续经过现有 runtime reducers 和 policy surfaces。

## Acceptance Criteria

1. rollbackable code-agent proactive edits can route as `routed` rather than `needs-affirmation` when marked low-risk.
2. software / desktop-like proactive side effects still require affirmation.
3. same inner carrier can continue a private thought across ticks.
4. dream can recover fatigue and also cool proactive opening momentum.
5. autobiographical episodes can surface as a dedicated recall source in organic memory prompt blocks.
6. Targeted tests pass.
7. `pnpm -F @proj-alicization/stage-tamagotchi typecheck` passes.

## Product Acceptance Criteria

1. Alicization will sometimes just do the small safe thing instead of always asking first.
2. She will feel less like a turn-by-turn shell and more like she is still carrying a thought from earlier.
3. Her self-history will be easier to re-enter as lived memory rather than only as fact or continuity residue.

## Completion Language Policy

Only use completion wording if:

1. risk-band autonomy is wired into actual planning/dispatch behavior
2. private-thought carry is live in the runtime
3. dream recovery affects proactive rhythm
4. targeted tests and stage typecheck pass

## Delivery Truth Contract

1. Do not claim the whole “真人一样” agenda is finished.
2. Only claim this slice closed risk-band autonomy, private-thought carry, autobiographical episode prompt usage, and dream rhythm recovery.

## Non-Goals

1. Do not claim complete life-rhythm/circadian simulation.
2. Do not claim all dialogue lanes are now fully governed by a single self authority.
3. Do not claim all proactive desktop/software actions can self-start.
