## 待机验收的输入归属

120 秒 host viewport 实测没有自动播放动作，静默嘴巴保持关闭，表情不循环；头部幅度检查失败。该运行同时接收用户桌面上的真实鼠标移动，缺少注视来源采样，不能仅凭幅度认定自主待机逻辑故障。后续短时同一编译版本的采样中，自主视线数秒才更新一次，幅度约 0.12；静止的外部坐标没有持续续租。

因此增加实际渲染器的注视归属诊断：本地指针、外部注意、自主待机，以及剩余占用时间。被本地交互拒绝的外部采样不能更改当前归属。默认产品的跟随逻辑不变。

验收新增显式 `LIFE_EXPRESSION_ISOLATE_IDLE_POINTER=1` 模式，只在测量自主待机时临时使用已有 `disableFocusAt`，随后恢复原值；不操作主桌面的鼠标、焦点和显示设置。原有头部小于 8 度、嘴巴、表情、呼吸、眨眼阈值保留，并检查测量帧确实已释放指针归属。恢复后继续真实 Cubism 左右眼球响应、局部注视取得与释放检查。该模式是隔离输入的校准证据，不证明 Default 桌面的物理输入投递。
